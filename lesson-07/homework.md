# Домашнее задание #05 (потоки, процессы)

### 1. Пул потоков с приоритетом
Класс `PriorityThreadPool` должен позволять:
1) запускать произвольные задачи в несколько потоков-воркеров;
2) выполнять задачи на основе их приоритета;
3) изменять количество активных потоков динамически (если поток простаивает дольше `keep_alive_time` секунд, он должен завершаться для экономии ресурсов);
4) возвращать специальный объект для ожидания результатов задачи.

Необходимые элементы реализации:
 - `enum` с приоритетами, например, `low`, `medium`, `high`, но можно и другие;
 - возможность ограничения очереди под капотом;
 - `PriorityThreadPool.submit` (pool.submit(func, *args, priority=2)) отправляет задачу с каким-то приоритетом в очередь и возвращает `TaskResult`;
 - `TaskResult.get_result` позволяет получить результат задачи или выбрасывает исключение, если таковое было при выполнении задачи;
 - когда для воркера нет задач в течение `keep_alive_time` (например, 5 секунд), данный воркер должен завершить свое выполнение;
 - при поступлении новых задач, если текущих живых потоков меньше `max_workers`, пул должен автоматически досоздать потоки-воркеры;
 - `PriorityThreadPool` должен поддерживать интерфейс контекстного менеджера;
 - использовать готовые пулы нельзя.


По желанию, для усложнения задания можно сделать переключатель на пул из процессов.
