# Домашнее задание #02 (ООП, ABC)

### 1. Cистема обработки событий (Strategy)

1) Класс событий `Event`
Обязательно должны быть поля: `level`, `data` и `is_persistent`,- но можно вводить дополнительные по необходимости.
А также методы для "красивого" вывода события.

2) Реализация ABC `EventHandler`
`EventHandler` должен содержать абстрактные методы:
  - `handle(event: Event)` для обработки события `event`;
  - `get_type` для получения типа хендлера в видео строки.

`EventHandler` должен уметь проверять виртуальное наследование подклассов.

3) Реализация нескольких конкретных обработчиков через неследование `EventHandler`
  - `StreamHandler` должен записывать событие в консоль через `print`;
  - `EmailHandler` должен эмулировать отправку события через email в методе `send_email(recipient, subject, body)`, саму отправку реализовывать не нужно, достаточно выводить данные;
  - `FileHandler` должен записывать событие в файл, но только если у события есть поле `is_persistent=True`;

Каждый хендлер должен обрабатывать уровень `level` события, как в логировании (обрабатывать только события своего уровня или выше).
Конфигурация каждого хендлера должна выполняться до отправки событий.

4) Класс `EventDispatcher`
  - `register_handler(handler: EventHandler)` добавляет хендлер;
  - `dispatch(event: Event)` Проходит по всем зарегистрированным хендлерам и вызывает `handler.handle(event)`;
  - `remove_handler(handler_type: str)` удаляет все хендлеры данного типа.

Метод `dispatch` должен работать одинаково для любого хендлера, независимо от его внутренней реализации.
