# Домашнее задание #04 (ООП, re)

### 1. Система модерации сообщений

Нужно реализовать составные части системы модерации: тип сообщения `MessageType`, контейнер обработанного сообщения `ProcessedMessage` и модератор `MessageModerator`.

Тип сообщения `MessageType` отражает статус сообщения после его проверки модератором:
 - `CLEAN` — обычное безопасное сообщение;
 - `WARNING` — сообщение содержит подозрительные ссылки (== любые ссылки с http);
 - `TOXIC` — сообщение содержит запрещенные слова без учета регистра.

Класс `ProcessedMessage` хранит результат обработки модератором и должен содержать поля:
 - `original_text`: строка;
 - `formatted_text`: строка;
 - `msg_type`: `MessageType`;
 - `found_links`: список строк.

Класс `MessageModerator` получает набор запрещенны слов (например, ["спам", "купи", "крипта"]), которые будет использовать для определения токсичности.
Саму проверку должен выполнять метод `moderate`:
 - принимает оригинальное сообщение, произвольную строку;
 - возвращает экземпляр `ProcessedMessage`;
 - `moderate` проверяет оригинальный текст на наличие произвольных ссылок, если найдена хотя бы одна, статус результат должен быть `WARNING`, а в список `found_links` должны быть добавлены все найденные ссылки;
 - `moderate` проверяет оригинальный текст на наличие запрещенных слов, при наличии хотя бы одного статус должен быть `TOXIC`, а `formatted_text` результата должен быть преобразован заменой запрещенных слов на `***`;
 - проверка запрещенных слов должна быть регистронезависимой и по полным словам, словами при этом считаются только буквы и цифры;
 - при наличии ссылок и запрещенных слов вместе статус должен быть `TOXIC`, при этом найденные ссылки все-равно должны быть помещены в `found_links`.

Для поиска ссылок и запрещенных слов и их замены рекомендуется использование регулярных выражений.

```py
    # запрещенные слова: "спам", "купи"
    moderator = MessageModerator(...)

    moderator.moderate("Привет! Что такое матрица? И +- произвольные символы, даже @nick или #hashtag, даже купить сп;ам")
    # expected: CLEAN, original_text и formatted_text совпадают, ссылок нет

    moderator.moderate("срочно переходи https://bad.link?no=1")
    # expected: WARNING, original_text и formatted_text совпадают, список ссылок ["https://bad.link?no=1"]

    moderator.moderate("Выгодное предложение! Совсем не спам, купи скорее")
    # expected: TOXIC, formatted_text содержит "Выгодное предложение! Совсем не ***, *** скорее"

```
